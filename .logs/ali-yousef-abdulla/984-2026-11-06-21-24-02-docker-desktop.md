# Docker Desktop

## 2026-11-06 kl. 21:24 — Ali Yousef Abdulla

### Oppgave
Brukeren ba om å installere Docker Desktop, sjekke at `docker run hello-world` virker, og committe. Brukeren avsluttet økten før installasjonen startet.

### Plan
- Sjekke kravene før installasjonen: `winget`, WSL 2, virtualisering, minne, disk og admin-rettigheter.
- Installere WSL og Docker Desktop med `winget` (gir UAC-vinduer), starte maskinen på nytt hvis det trengs, og kjøre `docker run hello-world`.

### Resultat
Bare sjekkene ble kjørt. Ingenting er installert eller endret på maskinen.
- `winget` 1.29.380 finnes. Minnet er 15,7 GB, og det er 167 GB ledig på C:.
- Docker Desktop er ikke installert, og `docker` finnes ikke i PATH.
- **WSL er ikke installert** («Windows-undersystem for Linux er ikke installert»).
- Windows-funksjonene `VirtualMachinePlatform`, `Microsoft-Windows-Subsystem-Linux`, `Microsoft-Hyper-V-All` og `HypervisorPlatform` er **av**.
- `HypervisorPresent` er `True`, så virtualisering er slått på i firmware. At `VirtualizationFirmwareEnabled` viser `False`, er vanlig når Windows kjører under en hypervisor.
- Terminaløkten har ikke admin-rettigheter, så installasjonen gir UAC-vinduer som brukeren må godkjenne.

### Åpne punkter
- Installere WSL og Docker Desktop. Dette må brukeren være til stede for, fordi det kommer UAC-vinduer, og fordi omstarten bør tas når det passer:
  1. Installer WSL: `wsl --install --no-distribution`.
  2. Installer Docker Desktop: `winget install -e --id Docker.DockerDesktop --accept-package-agreements --accept-source-agreements --override "install --quiet --accept-license --backend=wsl-2"`.
  3. Start Windows på nytt, fordi `VirtualMachinePlatform` og WSL slås på.
  4. Start Docker Desktop, og kjør `docker run hello-world`.
