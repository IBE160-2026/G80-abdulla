# Docker Desktop

## 2026-11-06 kl. 21:24 — Ali Yousef Abdulla

### Oppgave
Brukeren ba om å installere WSL og Docker Desktop, sjekke at `docker run hello-world` virker, og committe. Første gang (21:24) avsluttet brukeren økten etter sjekkene. Installasjonen ble gjort fra 21:26, og sist oppdatert 22:41.

### Plan
- Sjekke kravene: `winget`, WSL 2, virtualisering, minne, disk og admin-rettigheter.
- Installere WSL og Docker Desktop med UAC-vinduer som brukeren godkjenner.
- Starte maskinen på nytt og kjøre `docker run hello-world`.

### Resultat
- Sjekkene viste:
  - WSL var ikke installert, og `VirtualMachinePlatform` var av.
  - Virtualisering er på (`HypervisorPresent`), det er 15,7 GB minne og 167 GB ledig på C:.
  - Terminaløkten har ikke admin-rettigheter.
- Første forsøk med `wsl --install --no-distribution` (brukeren godkjente UAC) feilet etter 49 minutter med «Tilkoblingen til serveren ble tilbakestilt». Linja var treg og ustabil (1,4–5,9 Mbit/s), og forbindelsen til GitHub brøt rundt 69 %. Ingenting ble installert.
- Ny fremgangsmåte, mer robust:
  - WSL 3.0.3 (`wsl.3.0.3.0.x64.msi`, 350,5 MB) ble lastet ned med `curl` i en løkke som fortsetter der den slapp. SHA-256 er kontrollert mot GitHub (`ae977286…f211`), og signaturen er gyldig og utstedt til Microsoft Corporation.
  - Docker Desktop 4.98.0 ble lastet ned med `winget download`. `winget` bekreftet kontrollsummen, SHA-256 (`cd6273d9…4388`) er den samme som i manifestet, og signaturen er gyldig og utstedt til Docker Inc.
- Én installasjon med administratorrettigheter (ett UAC-vindu, godkjent av brukeren), 22:37–22:40:
  1. `msiexec` for WSL-pakken: kode 0. WSL 3.0.3.0 er installert.
  2. `dism` for `VirtualMachinePlatform`: kode 3010, som betyr at det gikk bra, men at maskinen må startes på nytt.
  3. Docker Desktop installert med `install --quiet --accept-license --backend=wsl-2`: kode 0. Versjon 4.98.0.245422, `docker.exe` finnes, og brukeren er med i `docker-users`.
- Windows venter på omstart. Installasjonsfilene ligger i scratchpad og er ikke i repoet.

### Åpne punkter
- Starte Windows på nytt, starte Docker Desktop, vente til motoren kjører, og så kjøre `docker run hello-world`.
- Linja er treg og ustabil. Første `supabase start` i Story 1.1 laster ned flere GB, så det bør gjøres på et raskere nett.
