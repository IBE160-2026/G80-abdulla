# README på ren maskin

## 2026-11-22 kl. 15:25 — Ali Yousef Abdulla

### Oppgave
Ta handlingspunkt 2 fra retroen for Epic 4: få README prøvd på en ren maskin, inkludert `npm run dev`, og måle første nedlasting. En helt ren maskin og en person som ikke kjenner prosjektet kan jeg ikke lage selv. Prosjekteieren valgte å rydde cachene på denne maskinen og følge README i en ny klone.

### Plan
- Stoppe lokal Supabase uten sikkerhetskopi, slette Supabase-bildene i Docker (11 stk.) og Playwright-nettleserne (741 MB).
- Ny klone av `main` (`7f22dc3`) i en kort sti (`k44`), og følge README ordrett med tid per steg: `npm ci`, `npx supabase start`, `cp .env.example .env`, `npx playwright install chromium`, `npm run dev`, og så full `npm test`. `scripts/skjermbilde.mjs` kontrollerer at lista viser åtte rapporter.
- Skriptet lå i scratchpad (`ren-maskin.sh`), ikke i repoet.

### Resultat
- **Tider:** `git clone` 6 s, `npm ci` 39 s, `npx supabase start` 7 min 25 s, `npx playwright install chromium` 2 min 27 s, `npm run dev` (forsiden svarte 200 etter 22 s), `scripts/skjermbilde.mjs` 17 s (åtte rapporter i lista, moderatorsiden), `npm test` 15 min 41 s (1108 Vitest, 53 databasetester og 284 Playwright-tester, alle bestått). Til sammen 27 min 6 s.
- **Avvik fra README:** `npx supabase start` fikk `toomanyrequests: Rate exceeded` fra `public.ecr.aws` og hentet `postgres-meta` og `kong` fra `ghcr.io` med automatiske nye forsøk. README sa at alle sju bildene kommer fra `public.ecr.aws`, og 3–5 minutter. Pg_prove-bildet (det åttende) lastes først i `npm test`, og det sto allerede i README.
- **Min feil underveis:** jeg sa først at `supabase start` hentet 5 bilder mot de sju README sier. Skriptet telte bare bildene fra `public.ecr.aws`. Det var sju (5 fra ecr og 2 fra ghcr).
- **README og `docs/testdekning.md` er oppdatert** med de målte tidene, opprinnelsen til bildene og to hull (se under). `issues.md`: punktet om første oppstart er lukket. `sprint-status.yaml`: `epic-4-retro-item-12-…` er `in-progress`, siden en annen person og macOS gjenstår.
- Tiden CI bruker på PR-en for denne endringen (README endret, så den kjører) er ikke sett når loggen skrives.

### Åpne punkter
- Gjort av utvikleren selv på Windows. En annen person som ikke kjenner prosjektet, eller en maskin med macOS, har ikke prøvd README.
- Innlogging og flyten i nettleseren er ikke prøvd for hånd i denne målingen, bare via Playwright (284 tester) og `skjermbilde.mjs`.
